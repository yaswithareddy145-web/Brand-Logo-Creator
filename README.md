# 🎨 AI Logo & Brand Creator
A lightweight, open-source AI logo generator that instantly designs minimal, vector-ready logos and text branding assets.
## ✨ Features
- **Text-to-Logo generation:** Generate sleek logos from simple brand prompts.
- **Customization presets:** Toggle between minimal, corporate, and abstract styles.
- **Multi-format export:** Download assets seamlessly in SVG, PNG, or favicon sizes.
